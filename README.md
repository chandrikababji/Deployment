# Saichandrika Kanaparthi | Portfolio

Personal portfolio of **Saichandrika Kanaparthi**, Full Stack AI Developer and Associate Software Engineer.

Designed and built from scratch with HTML, CSS and JavaScript (no template).

## Features

- Interactive neural network background and animated AI hero section
- "Ask My AI" assistant that answers questions about my work
- Work experience timeline, skills, projects, education, certifications and achievements
- Light and dark theme, fully responsive on mobile

## Project structure

```
portfolio/
├── index.html   page layout
├── style.css    design and animations
├── script.js    interactions and rendering
├── data.js      all content (edit this file to update the site)
└── img/         images
```

## Run locally

Open `portfolio/index.html` in any browser. No build step is needed.

## Deploy

Deployed on Vercel with the **Root Directory** set to `portfolio`.
